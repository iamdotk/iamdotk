# Dhanasekaran Kathiresan

I build [OpenMoat](https://github.com/crocodile-labs/openmoat) at Crocodile Labs: open-source
security for AI coding agents. It checks every command, file access, web request and MCP call an
agent makes before it runs, and blocks the dangerous ones, across Claude Code, Codex, Cursor,
OpenClaw, GitHub Copilot CLI, pi and Gemini CLI.

**What I'm working on**

- [OpenMoat](https://github.com/crocodile-labs/openmoat): the policy engine, hooks, OS sandboxes
  and egress proxy, in Rust. OpenSSF Best Practices passing.
- [OpenMoat Bar](https://github.com/crocodile-labs/openmoat-bar): a read-only menu bar and tray
  app for it, in Swift and Qt.
- [openmoat.dev](https://openmoat.dev): the docs and the blog, where I write about keeping coding
  agents away from your secrets.
- [tracedog](https://github.com/iamdotk/tracedog): Datadog APM from your terminal.
